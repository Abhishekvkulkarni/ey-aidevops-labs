1. Concept 10 min · trainer (Anil) leads

A pipeline is a spec that runs. Treat it like one.

Four gates, in this order

lint → test → build → deploy

Cheap checks first. Each job needs the one before it, so bad code never reaches the cluster.

Three habits to verify in AI-written YAML

1. Image tag is the commit SHA, not latest.
2. Secrets come from GitHub secrets, never from the file.
3. Every action has a version tag.

Tests need testing too. A suite can show high coverage and still let bugs through. The mutation check injects 6 known bugs and counts how many your tests catch.

[s3] Add a Trivy gate to the pipeline
Ask Copilot to add a step after build that scans the pushed image and fails on HIGH or CRITICAL findings. If it stays green first time, tighten the severity once to see it block, then undo.
