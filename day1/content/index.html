Ground level

Your VM. Your keyboard. Start.

Do these once. Tick as you go.

  1. Get the code (once), in PowerShell on your lab VM. Fork and clone the repo, then open day1\content\index.html from that folder: 
    gh auth login
cd C:\EYLAB
gh repo fork askanilkumar/ey-aidevops-labs --clone
cd ey-aidevops-labs
gh repo set-default (git remote get-url origin)
  2. Load your lab card (every new terminal). After the code is cloned, run: 
    . C:\EYLAB\ey-aidevops-labs\lab-env.ps1
    It reads C:\EYLAB\lab-card.json, which the trainer placed on your VM.
  3. Each morning: run .\sync.ps1 in the repo folder to get that day's pages.
  4. Open pages by double-click from your cloned folder, not on github.com (that shows source, not the page). Any browser.
How every lab page works: run a command, paste the output into the page, press Check. It scores in your browser. At the end press Copy my result and paste it in the call chat.
Rule of the day: trust but verify, with numbers. The AI does not grade itself.
