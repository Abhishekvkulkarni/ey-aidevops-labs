1. Concept 10 min · trainer (Anil) leads

A pull request lands. Two reviewers look at it: a scanner and an AI. Who catches what?

Scanner (Trivy)

Fast, repeatable, rule-based. Strong on known patterns such as leaked secrets and risky infrastructure settings.

AI reviewer

Reads the code like a person. Can follow logic and context, but varies between runs and sometimes invents problems.

How we score. The PR has 5 planted issues. You get 20 points for each one found by any tool, and minus 5 for each false positive. Matching is by file and category, so be precise about both.

3. Solo challenge 30 min · you work alone

Make the AI reviewer better by treating its prompt as a spec, and prove it with the score.

Take away the context
Run the reviewer on the diff only and score it. Use the --no-context box under Paste and check. Note what changed.
Rewrite the reviewer prompt as a spec
Open day1/labs/block3-ai-review/ai_review.py and find the review prompt. Rewrite it with:
  • the allowed categories: hardcoded-secret, injection, broken-access-control, iac-misconfig, logic-bug
  • required output for each finding: file, line, category, and the evidence from the code
  • a rule to report nothing rather than guess
Run and score your version
Use the Solo box. Compare it to your earlier scores in the result panel.
Reveal the answer key
Only after all four scores are pasted. Use the last box and write your verdict.
Stretch: run your reviewer three times. Do the findings change between runs? What does that say about using a single AI run as your only review?
