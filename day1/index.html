Before you start

  • Work on your lab VM. Open a PowerShell terminal and run . C:\EYLAB\ey-aidevops-labs\lab-env.ps1 to load your lab card.
  • Get the code (once). Fork and clone the repo, then open day1\index.html from that folder: 
    gh auth login
cd C:\EYLAB
gh repo fork askanilkumar/ey-aidevops-labs --clone
cd ey-aidevops-labs
gh repo set-default (git remote get-url origin)
  • Each morning: run .\sync.ps1 in the repo folder to get that day's pages.
  • Open these pages from your cloned or downloaded folder (double-click the file). Do not open them on github.com: that shows the source, not the page. Use any browser. Copy commands with the Copy button.
  • After each command, paste the output into the page and press Check. The page scores it instantly, in your browser.
  • At the end of each page, press Copy my result and paste it in the call chat.
Rule of the day: trust but verify, with numbers. The AI does not grade itself.
