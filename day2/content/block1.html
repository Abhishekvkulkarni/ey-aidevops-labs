Lab 1: Tests you can trust

Goal: see why tests written from a spec catch bugs, and tests written from the code do not. About 25 minutes.

Folder: day2\labs\block1-tests. rates.py is a price calculator, rates-spec.md is what it SHOULD do. rates.py has 2 hidden bugs. Do not open either file yet.

🤖 What AI adds
Writes a dozen or more tests in seconds, runs them, reads the failures and points at the exact line. By hand: typing every test and debugging each failure.
🧠 What only you add
The requirement (the spec), and the judgment: is the code wrong, or the test? Only you decide what is correct.

Copilot Chat must be in Agent mode (mode picker at the bottom of the chat box). If it asks to run a command, click Allow. You do not need to open a terminal in this lab.

Step 1: tests from the code

💬 COPILOT CHAT (Agent mode)
Paste:
Read #file:rates.py and write pytest tests for quote() in day2/labs/block1-tests/test_from_code.py. Aim for good coverage. Then run: python -m pytest -q in that folder and show me the result.
Predict first: Will they all pass? Does a green run mean the code is correct?

Step 2: tests from the spec

💬 COPILOT CHAT (Agent mode)
Paste. Copilot writes the tests, runs them, and diagnoses the failures:
Read #file:rates-spec.md. Write pytest tests for quote() in day2/labs/block1-tests/test_from_spec.py using every worked example in the table and every edge case. Do NOT read rates.py while writing the tests; import it with: from rates import quote
Run them with python -m pytest test_from_spec.py -q in that folder.
Do not edit the spec, the tests or rates.py yet. For each failing test, now read rates.py and tell me which line is wrong and why.
Predict first: Some tests should FAIL. Each failure points at a bug.

Step 3: you decide, then fix

📝 EDITOR
Open rates.py. Check the lines Copilot blames against rates-spec.md. Does the spec back Copilot up? Copilot can be wrong; the spec decides.
💬 COPILOT CHAT (Agent mode)
If you agree, paste:
Fix those two lines in rates.py and rerun all tests in this folder. Then tell me: why did test_from_code.py pass before the fix, and does it still pass now?
📝 EDITOR
Review the change Copilot made to rates.py (it should be 2 small edits), then click Keep.

Check yourself

⭐ Takeaway
Tests written from the code repeat the code, bugs included. Give the AI the requirement, not the implementation. A green run only means something if the tests came from somewhere independent. Let the AI run the loop; you review the diff.

Reusable prompt:

Read the requirement in #file:SPEC. Write pytest tests for FUNCTION using every example and edge case in it. Do not read the implementation while writing them. Run them, and for each failure say which line is wrong and why. Do not change the spec or the tests. If the spec is unclear, list your questions first instead of guessing.

If stuck: no Agent option in the chat? Use Ask mode, copy the code Copilot gives you into the file, and run python -m pytest -q in a terminal opened in the lab folder. Copilot edited the wrong file? Press Undo in the chat, or Ctrl+Z.
